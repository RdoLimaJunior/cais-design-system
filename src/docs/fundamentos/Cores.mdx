O fundo suave de um estado é a própria cor com 10% de opacidade (`bg-success/10`). Os sistemas (PMO, SCSP) usam estas cores; se um sistema precisar de uma cor nova, ela é derivada de uma destas, nunca um valor solto.

## Tokens do tema (shadcn)

O tema também define os tokens do shadcn/ui (`--primary`, `--muted`, `--border`, `--ring` e outros) em
`src/styles/globals.css`, com versão para modo escuro (`.dark`). Eles foram copiados do CSS do FAROL e
não devem ser alterados sem validar com a design.

**Exceção feita para o PMO:** o `--primary` era um azul-petróleo que nenhuma tela usava e passou a ser o azul da marca, `#0089E2`. Confirme com a design.
