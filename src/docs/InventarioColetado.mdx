# Inventário do que foi coletado

Tudo que foi levantado do FAROL, de onde veio e onde está no Storybook. Serve como mapa para o próximo sistema e
como lista do que ainda falta.

## Fontes

| Fonte | O que deu | Observação |
| --- | --- | --- |
| **Site em produção** (`farol.institutocais.org.br`) | HTML, CSS, estilos computados, ícones, fonte, favicons, manifest, fluxo de telas | Capturado com a conta de **Bolsista**; telas de RH não abrem para esse perfil |
| **JavaScript público do site** | Lista de rotas, bibliotecas usadas (React Router, Sonner, react-hook-form, zod, Radix, Tabler) | Só estrutura; nenhum dado |
| **Figma do Farol** | Visão de administrador do menu, componentes, protótipo de alto contraste | O arquivo é do time de design; vale como referência, **o site vence** em caso de conflito |
| **Medições no navegador** | Escala de fonte (100% a 130%), chaves do `localStorage`, regras de cursor | Feitas com o Playwright |

## O que ainda não foi possível capturar

- **Textos de erro e de sucesso**: mensagens de validação dos formulários e dos toasts (exigem enviar formulário de verdade). Estão marcados como *provisórios* no código.
- **Outros estados do relatório mensal**: devolvido para correção, aguardando revisão, assinatura pendente.
- **Telas de RH**: só a estrutura (rotas) é conhecida.
- **Telas estreitas** (tablet e celular), **hover** e **foco**: ainda não medidos.
