# Mapa de ícones: Lucide para Tabler

O PMO atual usa Lucide (`react-icons/lu`); o design system usa Tabler (`@tabler/icons-react`).
Os nomes abaixo foram **conferidos contra o pacote instalado**: todos existem.

## Como trocar

```tsx
// Antes
import { LuTrash2 } from 'react-icons/lu'
<LuTrash2 size={16} />

// Depois
import { IconTrash } from '@tabler/icons-react'
<IconTrash size={16} aria-hidden="true" />
```

- Ícone **decorativo** (ao lado de texto) leva `aria-hidden="true"`.
- Ícone **sozinho** em botão: o botão leva `aria-label`.
- A espessura do traço do Tabler é um pouco diferente; confira visualmente nos botões pequenos.
- Os ícones `LuPencil` e `LuPencilLine` apontam para o mesmo `IconPencil`.
